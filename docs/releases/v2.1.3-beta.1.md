# v2.1.3-beta.1 local candidate

## Displaying a VOC index

In setup or Options, open Telemetry and choose **VOC index (display only)**. Add
the provider's index sensor and give it a distinct label. Each V2 row shows that
provider's raw finite index when its unit is empty or explicitly “index”. Zero is
a valid reading. Providers can use different scales. Concentration sources keep
their configured roles and ppm-to-ppb normalization. A missing concentration
source continues to contribute missing evidence to its existing consumers.

The effective `voc_index_sources` collection holds a source key, provider entity
binding and display label per row. An explicit empty Options list clears setup
defaults. A label edit retains the key. Selecting a different provider entity ID
creates a new binding unless the registry verifies that the same provider was renamed.
For a registered provider, the row also stores a private, per-row identity digest.
Reselect the renamed sensor in Options to retain its source key. A replacement
that takes over the old entity ID cannot supply its readings. To choose that
replacement deliberately, remove the old index row and add the new provider.
Registry continuity identifies the HA record. It cannot verify physical hardware. For an unregistered
source, HI can verify only its configured entity ID. A missing source stays visible
as unavailable.

One optional entry-owned sensor counts reporting sources. Its `schema: 1` and
`readings` attributes provide a label, status and value per opaque source key.
All configured providers can be unavailable while the reporting count is zero.
Index values have no house average, control threshold, CO role or Stability credit.
Recorder excludes the feed's per-source readings attribute. Native diagnostics
downloads and HI support dumps expose counts for this feature.

## Generated cards and upgrade

The original beta.1 export is revision 17. The AQ colour follow-up advances both
V2 layouts to revision 18 and supersedes revisions 1–17. The stamp
schema and generator contract remain 1 because entry binding and revision comparison
retain their meanings. Existing saved cards keep their embedded behaviour until
replaced. For an authorised installation, install the complete integration, restart
Home Assistant, refresh mappings, export and replace each complete V2 card. Refresh
exports after adding or changing bindings. If the whole index feed is missing, a
card can display the labelled sources from its export as unavailable.

### AQ chip display bands

House and level chips use the same HI display bands. The backend classifies the
displayed average after converting the inputs to the metric's canonical unit.

| Measurement | Green (band 1) | Amber (band 2) | Red (band 3) |
| --- | --- | --- | --- |
| IAQ (index) | Above 60 | Above 50 through 60 | 50 or below |
| PM2.5 (µg/m³) | Below 35 | 35 to below 65 | 65 or above |
| VOC (ppb) | Below 40 | 40 to below 60 | 60 or above |
| CO (ppm) | Below 10 | 10 to below 15 | 15 or above |

These are the historical HI card display bands. Colour describes the number on
that chip. Ventilation uses the configured triggers for each level. CO emergency
uses individual CO sources and its own clearance policy. A green house average
can coexist with an active alert. Incomplete source coverage keeps the value
neutral. Each display-only VOC index keeps its own label, scale and neutral value.

## Downgrade

Before changing packages, capture the current Options and the two saved card
subtrees. If index sources were configured, remove only those rows in the supporting Options flow
and save. Verify the explicit empty collection, retirement of the owned index
sensor and preservation of unrelated settings, including missing concentration
inputs. An installation that never configured an index can skip this Options step. Restore the previous compatible package, restart, and replace only the
affected cards with matching exports. Compare the current subtrees before
replacement to preserve intervening edits. Reload and restart reset in-memory
Stability history. No database rewrite is required.
