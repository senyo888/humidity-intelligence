# v2.1.3-rc.1 release candidate

The final beta.1 and the original RC.1 build at `5870165` exported revision 18.
The first review corrections at `4e8682d` exported revision 19, and `e5828ca` exported
revision 20. Mobile and Tablet now use **revision 21**. The stamp schema and
generator contract remain **1**. Package and installation evidence
for the beta and original RC belong to those builds.

## Card compatibility and upgrade

Install the complete integration and restart Home Assistant. Refresh the mappings,
export each layout you use and replace the full saved card if it is revision 20
or earlier. A current revision-21 card with matching bindings can stay in place.

Complete AQ averages show the value and unit in the threshold colour. Screen
readers also announce the display range. House
averages include valid configured AQ readings that have no assigned floor. Floor
averages use only readings assigned to that floor. Risk badges use the reported risk of the current room. For rooms named exactly
`unknown` or `unavailable`, the matching entry’s risk sensor confirms the label. Back and
Escape cancel pending history actions when a card is refreshing. If the destination
entity disappears before native details open, the current dialog stays open.
When the leading chip shows the reported operating mode, it uses the history
swatch. An active alert, CO emergency or AQ condition can take precedence on the
live chip.

VOC index feed schema 2 identifies the owning configuration entry. Revision-17
and revision-18 cards with configured index sources show their saved labels as unavailable on the new feed.
Cards from revision 19 onward do the same with an older feed or a different
entry. Installing the matching card and backend restores live per-source readings. The feed change requires no Options migration. Index
sources stay display-only, and existing concentration mappings keep their roles.

## Rollback

To return to the final beta.1 or original RC.1, restore that complete package
and restart Home Assistant to load it. Then restore the matching saved revision-18
cards. Keep the index sources and concentration mappings. To downgrade to a version that predates index support, first clear any
configured display-only index sources in Options while running the supporting
version. Verify the saved empty index list and retained concentration mappings,
then restore the previous package, restart Home Assistant and restore its matching cards. [Detailed downgrade steps](v2.1.3-beta.1.md)
