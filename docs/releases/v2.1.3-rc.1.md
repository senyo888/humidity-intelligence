# v2.1.3-rc.1 release candidate

RC.1 carries forward the final beta.1 at `43e869fd740519f12b30ff45dd3c2f2ed619664e`.
The controller package builder and the admin release check now recognise this exact
RC version. The packaged UI guide corrects the final beta’s revision number to 18.
The manifest, service and packaged guide give RC.1 a distinct package identity.
Installation and runtime observations for the beta apply to the tested beta package.

## Card compatibility and upgrade

Both V2 layouts keep revision **18**, stamp schema **1** and generator contract
**1**. The card templates, renderer and entity bindings match the final beta.1.
Existing revision-18 exports with current bindings work with RC.1. For revision
17 or earlier, install the complete integration, restart Home Assistant, refresh
the mappings, export each layout you use and replace its complete saved card.

RC.1 introduces no configuration migration. Per-source VOC indices remain
display-only. Existing concentration inputs retain their configured roles.
The [beta compatibility record](v2.1.3-beta.1.md) describes the AQ display bands,
the optional index mapping and the steps for downgrading to software that predates it.
