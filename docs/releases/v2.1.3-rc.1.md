# v2.1.3-rc.1 release candidate

The final beta.1 and the original RC.1 build at `5870165` exported revision 18.
The reviewed RC.1 update advances Mobile and Tablet to **revision 19**. The stamp
schema and generator contract remain **1**. Package and installation evidence
for the beta and original RC belong to those builds.

## Card compatibility and upgrade

Install the complete integration and restart Home Assistant. Refresh the mappings,
export each layout you use and replace the full saved card if it is revision 18
or earlier. A current revision-19 card with matching bindings can stay in place.

Complete AQ averages show their numeric band alongside the measurement. House
averages include valid configured AQ readings that have no assigned floor. Floor
averages use only readings assigned to that floor. Risk badges use the reported risk of the current room. For rooms named exactly
`unknown` or `unavailable`, the matching entry’s risk sensor confirms the label. Back and
Escape cancel pending history actions when a card is refreshing.

VOC index feed schema 2 identifies the owning configuration entry. Revision-17 and revision-18 cards with
configured index sources show their saved labels as unavailable on the new feed.
Revision-19 cards do the same with an older feed or a different entry. Installing the matching card and backend restores
live per-source readings. The feed change requires no Options migration. Index
sources stay display-only, and existing concentration mappings keep their roles.

## Rollback

To return to the final beta.1 or original RC.1, restore that complete package
and its matching saved revision-18 cards. Keep the index sources and concentration
mappings. To downgrade to a version that predates index support, first clear any
configured display-only index sources in Options while running the supporting
version. Verify the saved empty index list and retained concentration mappings,
then restore the previous package and matching cards. [Detailed downgrade steps](v2.1.3-beta.1.md)
